# 恐龙椅子手机支架

按上传图片复刻绿色恐龙椅子：饱满圆润的圆拱头部、中间微鼓的奶白鼻嘴与更圆润、略向前倾斜的独角、圆润深色眼睛、两个鼻孔、贴紧头部侧面的圆润背刺、低幅上翘的圆润小尾巴、双短脚靠背、奶白双槽座面、四根外撇深色椅腿。

## 尺寸与默认值
用户给出高11、宽8、深6.5左右，默认单位为厘米，整体约110×80×68 mm；座面在原65 mm深度上仅向前扩出3 mm，最外手机槽保持原位，删除最里面的槽，原中间槽默认向恐龙方向移动2 mm。图片为单视角，未见背面的厚度与曲面按可见轮廓补全；不声称像素级或隐藏结构完全一致。默认采用PLA色彩显示；恐龙靠背通过双短腿插入座面对应双槽，鼻嘴裁切为与脸部贴合的独立实体，9枚背刺与恐龙主体布尔合并为一个实体，眼睛裁去埋入部分后为贴合脸部的独立实体，独角裁去埋入部分后贴合实心头顶，不含电子平台或外购紧固件。

## 功能与验收
座面两道横向圆底槽延续原图外观，可放置手机底边。恐龙后退并位于最后端平面中央，不与凹槽接触。默认整体后移2 mm，两道手机槽中心y−19.5、−4.5 mm，使双脚前缘与最后一道槽留约12.136 mm、双脚后缘与座面后端圆角起点留1.5 mm；靠背整体默认右移3.3375 mm，使含鼻嘴及尾巴的左右外边界居中；鼻嘴保持相对于主体向左偏移。默认手机含壳厚度约12 mm以内；没有指定机型，不承诺具体手机和平板的稳定性。交付带颜色的三维预览与STEP模型，检查正面、侧面、整体尺寸、实体有效性与有意连接。打印拆件、承载试验与切片不是本次交付。

## 面部轮廓
恐龙鼻嘴侧（自身右侧、正面左侧）脸颊按鼻嘴外沿勾勒，下半轮廓为椭圆弧，靠腿根的曲线末端默认下移1.5 mm至世界高度46.5 mm，均匀过渡到最外侧边缘并连续接入上方脸颊，为鼻嘴下沿留出更宽承托边，默认外侧再放出1 mm，以留出承托边并避开1 mm圆角；恐龙自身左侧（正面视图右侧）头顶至腿根采用一条饱满圆润的连续外凸曲线，默认控制点向外放出3.8 mm，保留腿根硬接折角；以v16轮廓为基础，减弱鼻嘴侧凹陷上方凸起，默认肩部内收1.5 mm并同步收敛上方弧线，均匀过渡至头顶；左腿根外侧保留硬接折角，主体前后侧轮廓圆角默认1 mm，连续延伸到短腿内外侧边缘，短腿底面及底边不倒圆；侧边背刺根部默认再内收1.2 mm，顶部两枚背刺略下压，以贴紧圆润的主体侧边。
白色鼻嘴左右两端轮廓圆润，以默认指数2.8的截面分布配合端部加密截面形成圆弧收口；中间为连续鼓起的曲面，中心上下各增加1.2369 mm、向前增加2.5 mm为默认微调量；避免大面积平面。双眼相对v19沿恐龙自身右侧移动5 mm（正面视图向左）、净下移3 mm（在v20基础上升高2 mm），中心高度77.5 mm，轮廓驱动宽3.6、高4.4 mm的圆润椭圆；默认用同尺寸椭圆截面放样重建圆润曲面，再以脸部y14 mm平面布尔裁去埋入部分，保留眼睛位置和间距，剩余深度约0.65 mm。

## 鼻嘴与尾巴细节
鼻嘴后方主体沿鼻嘴轮廓增加一体绿色基底来承托整个鼻嘴，默认随形基底驱动宽53.35、高30.011885、厚13 mm，中心高度61.16415 mm；其左侧与头部由同一连续轮廓构成。
白色鼻嘴高25.011885、宽49.35 mm；以脸部接触平面y14 mm做布尔差集，裁去埋入脸部的背面材料，裁切后最大深度8.25 mm，背面平整贴合脸部；鼻嘴默认沿恐龙自身右侧（正面向左）再移动1 mm，居中后的中心x为−12.4125 mm、z为60.5059425 mm，下沿保留默认高度48 mm，鼻孔半径0.9 mm保持；尾根半径默认5.6 mm，尾身用逐渐缩小的截面先形成轻微下凹，向右延伸，再连续过渡至低幅向右上方舒展的圆润尾尖。尾巴上方第七枚绿色背刺默认缩小至原尺寸70%，从顶部第一枚绿色背刺往下数，不计奶白独角。尾根加粗后，两枚尾部小刺随尾面位置调整，保持外露。

独角按参考图改为宽根逐渐收细的圆头锥形，默认根半径4.8 mm、高15 mm，尖端采用1.4 mm圆润帽端，向正前方倾斜8°，保留5°的小幅侧倾。恐龙两条短腿间距默认从12 mm扩大至16 mm，开口在两腿外边界之间居中，左右短腿设计宽度均为10.96 mm。裤裆轮廓下沿默认降低1.5 mm至世界高度46.5 mm，与自身右脸最低轮廓端点齐平。头顶为实心轮廓，独角用布尔差集裁去埋入头部的部分，底面贴合当前头顶曲面，保留现有独角外形与位置。

## 尾弧与小刺间距
尾根保持加粗，尾身截面逐渐收细，末端采用一体圆头；默认尾巴中段中心下凹1.3 mm、尾尖局部高度8.5 mm、向右延伸量17 mm、尾尖圆头半径1.6 mm。最后两枚尾刺的根部间距默认6 mm，随下凹及上翘轮廓安置，增加第七枚背刺、两枚尾刺及尾尖之间的视觉空间。

## 椅腿与座面连接
四条椅腿根部由一块薄平板连为一体，平板嵌入座面底部；椅腿上细下粗。默认连接板64×49×2.2 mm，底面与座面底面齐平，座面底部凹位深2 mm，顶部0.2 mm融合用于连续模型；拆件打印配合间隙另行设计。椅腿上端默认直径8.4 mm，下端11.2 mm，保留外撇及圆润脚端。两道弧形手机凹槽直径13.5 mm，槽深默认4.5 mm、中心间距15 mm；座面四周侧面圆角半径12 mm，上下边缘圆角半径4 mm，后端平面起点y约1.864 mm。

## 恐龙与座面插接
恐龙短腿底部为平直端面，横截面四角随侧面圆角呈R1圆角，底边不倒圆，插入座面后端对应双槽。默认每条短腿宽10.96 mm、厚13 mm，插入4 mm；槽宽11.36 mm、前后13.4 mm、深4.2 mm，四角R1.2配合腿部R1圆角，每侧及底部预留0.2 mm。插槽与最后手机槽间隔约11.936 mm，槽底与椅腿连接板凹位之间保留4.8 mm材料。配合精度需打印试样校准。

座面单侧前扩3 mm，前缘y−35.5 mm、后缘y32.5 mm；两道手机槽中心y−19.5、−4.5 mm；两条恐龙插槽坐标保持不变。
